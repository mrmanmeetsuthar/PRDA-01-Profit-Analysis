# PRDA-01: Startup Profit Analysis

## Project Overview

This project analyzes startup spending and profitability using Linear Regression and Power BI. The objective is to explore the relationship between research and development, administration, marketing expenditure, and profit.

## Objectives

* Analyze the relationship between startup spending and profit.
* Build a Linear Regression model.
* Evaluate model performance using regression metrics.
* Predict profit for two new spending scenarios.
* Present insights using Power BI dashboards.

## Tools Used

* Orange Data Mining
* Linear Regression
* Microsoft Power BI
* Microsoft Excel / CSV

## Dataset Features

* R&D Spend
* Administration
* Marketing Spend
* State
* Profit

## Model Evaluation

The reported model evaluation results are:

| Metric |          Result |
| ------ | --------------: |

| RMSE   |      14,911.997 |
| MAE    |      10,719.997 |
| MSE    | 222,367,654.594 |

These metrics describe the reported evaluation results. Performance may differ on unseen data.
